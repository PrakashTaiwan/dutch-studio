# Dutch Studio

A single-file web app for learning Dutch (Nederlands) — from A1 to C1, with a focus on business contexts (Tamil Nadu ↔ Netherlands investment talks).

**Live:** Enable GitHub Pages on this repo, or drop `index.html` onto [Netlify Drop](https://app.netlify.com/drop).

## Features

- **20 structured lessons** across A1, A2, B1, B2, C1 — grammar, vocabulary, examples.
- **7 flashcard decks** — Essentials, Daily Life, Verbs, Connectors, Business, False Friends, Idioms.
- **Searchable vocabulary library** filterable by topic (greetings, numbers, business, email, idioms, etc.).
- **6 business scenarios** — distributor meetings, factory tours, investment pitches, contract negotiation, trade-fair small talk, email phrases.
- **AI Tutor** — offline rule-based engine for translations, grammar, and business phrases. Optional Claude API key support for unlimited conversational tutoring.
- **Dutch text-to-speech** using the browser's built-in `nl-NL` voice.
- **Progress saved locally** in the browser (`localStorage`) — no server, no tracking.

## Use

Just open `index.html` in any modern browser. Works on Mac, Windows, iPhone, iPad, Android.

## Tech

One self-contained HTML file. No build step, no dependencies, no backend.
